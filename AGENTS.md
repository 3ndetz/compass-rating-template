# Инструкции для работы с рейтингом Compass

Поддерживай `compass.json` валидным JSON по формату версии 1: `version`, `title` и массив `ratings` с `item_id`, `rating` от 1 до 5 и `reason`. Используй только реальные идентификаторы из карточек Persona Lab Compass. Не выдумывай личный опыт и оценки автора. Сохраняй объяснения, ссылки, даты и решения автора; при изменении проверяй JSON и уникальность идентификаторов. Не включай секреты и частную переписку.
