# Мой рейтинг технологий

Сохраните рядом с этим файлом `compass.json` и опубликуйте репозиторий на GitHub или GitLab. В Persona Lab Compass вставьте ссылку на корень репозитория. Для обновления импортируйте ссылку повторно; у каждой версии сохраняется идентификатор коммита.

Формат версии 1 содержит название и список оценок. Для каждой технологии нужны её `item_id`, целая оценка от 1 до 5 и причина. Идентификатор можно скопировать из карточки технологии в Compass. В одном файле — не более 100 оценок, каждая технология встречается один раз. Рейтинг и текст будут публичными; не добавляйте секреты и чужие личные данные.

Скопируйте [пример compass.json](compass.json) и [инструкции для агентов](AGENTS.md) в свой репозиторий. Обычный README можно дополнять ссылками, объяснениями, примерами и разделами на свой вкус.
